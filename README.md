# TROVENDI — AI Commerce OS

Веб-платформа управления торговлей на маркетплейсах РФ и СНГ: подтверждённые данные → расчёт → AI-рекомендация → проверка и согласование → разрешённое действие → измерение результата.

**Архитектурное решение от 12.09.2026:** концепция одобрена для дальнейшей разработки. Коммерческая готовность и неограниченная автономия не одобрены. Основание — аудит исходного коммита `f090a4b3006ff72351d7c37696ae3d7c228e7805`.

## Код

| Каталог | Назначение |
| --- | --- |
| `web/app`, `web/components`, `web/lib` | Next.js / React, рабочие экраны и серверные proxy routes |
| `web/backend/app` | FastAPI, доменные сервисы, API, фоновые задачи |
| `web/backend/migrations` | Alembic; текущая цепочка исходного аудита заканчивается на 0027 |
| `web/backend/tests`, `web/tests` | Backend и CSV frontend tests |
| `studio`, корневые `app.py`, `tests`, `installer.iss` | Сохранённая desktop-ветка; не активная поставка веб-продукта |

Runtime и frontend поднимаются по [deployment contract](web/backend/DEPLOYMENT.md). Конфигурация production должна оставаться fail-closed. Секреты в Git не добавлять.

## Принятые границы

Wildberries — первая полная вертикаль; Ozon, Яндекс Маркет, Kaspi, Uzum и учётные системы подключаются через общий контракт. Сеть фулфилментов и документный сейф — самостоятельные направления поверх общего tenant/store, событий, согласований и аудита. Наличие страницы, модели БД или зелёной сборки не означает, что функция готова в production.
